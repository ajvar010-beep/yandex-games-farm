# Поиск в интернете, когда WebSearch пуст

На этом окружении `WebSearch` периодически возвращает пустую выдачу на любой запрос —
и на кириллице, и на латинице, и в кавычках. Это не «ничего не найдено», это сломанный
бэкенд. `WebFetch` при этом работает нормально. Поэтому ищем через страницу выдачи.

## Порядок действий

1. **Сначала обычный `WebSearch`** — если вернул результаты, работаем с ними.
2. **Пусто → Bing через `WebFetch`.** Это основной рабочий обход:

```
WebFetch(
  url = "https://www.bing.com/search?q=" + encodeURIComponent("запрос"),
  prompt = "List the top organic results with title and URL. Say plainly whether any result is actually about <то, что ищем>. If none, say so."
)
```

Промпт важен: проси именно **заголовки и URL списком** и отдельно — **честное «нет»**,
если тема не нашлась. Иначе модель охотно пересказывает похожие сниппеты как ответ.

3. **Уточняй запрос по кругу.** Bing часто цепляется за одно слово: по запросу
`"Tower Destiny Survive"` он выдал десять результатов про башни вообще. Помогает:
добавить платформу («Google Play», «Яндекс Игры»), язык аудитории («игра»), снять кавычки,
попробовать аббревиатуру отдельно.

4. **DuckDuckGo HTML не использовать** — `html.duckduckgo.com/html/?q=...` отдаёт CAPTCHA
   с картинками («select image squares containing a duck»), результата не будет.

5. **Дальше — прямой `WebFetch` по найденному URL.** Только по URL из выдачи или из
   сообщения пользователя, не по угаданному адресу.

## Где что лежит

| источник | что даёт | подвох |
|---|---|---|
| `play.google.com/store/apps/details?id=...` | описание, фичи, монетизация | страница часто приходит **обрезанной** — пустой ответ вместо текста |
| `tds.wiki`, `*.fandom.com` | механики, тиры, цифры | фанатские вики, проверять дату |
| `yandex.ru/games/` | скан каталога, топы | нужен живой fetch, WebSearch по топам пуст |
| `itch.io`, `store.steampowered.com` | жанр, теги, отзывы | — |

Если страница обрезалась — не выдумывай содержимое. Возьми сниппет из выдачи (в нём
обычно есть одна точная фраза описания), попробуй альтернативный источник (APKPure,
AppBrain, обзор на сайте-гиде), либо скажи пользователю, что нужно.

## Правила

- **Никаких выдуманных цитат и фактов.** Если источник не открылся — так и говори.
- Всегда прикладывай найденные URL; в ответе пользователю — ссылками.
- Отличай «игра называется TDS» от «игра сокращается как TDS»: аббревиатуры общие,
  проверяй издателя и package id (`com.playstrom.hero.tower` — это Tower Destiny Survive,
  а `Tower Defense Simulator` — Roblox-игра от Paradoxum, другой продукт).
- Для JS-тяжёлых страниц последний резерв — локальный Chrome: в `pipeline/` уже есть
  puppeteer-core и путь к `chrome.exe` (см. любой `capture-*.mjs`); headless-загрузка
  страницы обходит часть блокировок.

## Вывод по разведке

- `WebSearch` — не работает на этом API, не тратить на него больше одного запроса.
- `WebFetch` + Bing — работает, это штатный путь.
- Google Play — работает, но текст обрезается.
