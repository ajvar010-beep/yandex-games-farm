# Фабрика игр — рабочий регламент (актуально на 2026-11-06)

Этот файл — практическая версия `ORCHESTRATOR.md` под реальные пути и команды репозитория.
Один шаблон, один рубрикатор, один цикл. Меняется механика и тема, не инфраструктура.

## Что где лежит

| В ORCHESTRATOR | В репозитории |
|---|---|
| `template/platform.js` | `games/<slug>/engine/*` — SDK/цикл/capture/storage; копируется из последней готовой игры 1:1 |
| `check.py` | `pipeline/pack.mjs` (пакет+медиа+тексты) + `pipeline/audit.mjs` (статика/рантайм/i18n) |
| `RUBRIC.md` | `RUBRIC.md` (100 баллов, порог 85) |
| `genres.md` | `genres.md` |
| `market/scan-YYYY-MM.md` | `market/scan-2026-11.md` |
| `games/<slug>/CHOICE.md` | есть для каждой игры |
| `games/<slug>/SPEC.md` | есть для каждой игры |

## Цикл новой игры (7 шагов)

### 0. Предполёт
```bash
node pipeline/smoke.mjs ../games/<эталон>   # из pipeline/
```
Эталон (например, arrowescape) должен быть зелёным: движок и capture-контракт живы.

### 1. Разведка
Живой fetch `https://yandex.ru/games/` и `/category/new` (WebSearch по топам пустой).
Фиксировать: топ-баллы 88–99, жанры топа, что в новинках. Результат — `market/scan-YYYY-MM.md`.

### 2. Выбор жанра и темы
`genres.md`: жанр из «брать», минимальная конкуренция, ноль внешнего арта.
Проверить иконку 128×128: силуэт читается без текста.
Результат — `games/<slug>/CHOICE.md` (10 строк + отличие одним предложением).

### 3. Спека
`games/<slug>/SPEC.md`: цикл, очки, проигрыш, мета, реклама, лимиты.

### 4. Сборка
```bash
cp -r games/<эталон>/engine games/<slug>/engine
cp games/<эталон>/sdk-stub.js games/<slug>/
```
Пишутся только `index.html` и `game/*.js`. Адаптер `engine/sdk.js` и `engine/core.js` не трогаются.
Порядок: ядро → HUD → экраны → звук → сохранения → реклама. Всё через `Platform.*`/`Engine.*`.

### 5. Медиа
```bash
node pipeline/capture-<slug>.mjs ../games/<slug> ../packages/<slug>/media ru,en
```
Скриншоты 1280×720 и 720×1280 (≥3 на язык), видео 26 с 1280×720 H.264,
иконка 512×512, обложки 800×470 (текст не обрезан). Промо-арт — не скриншот (5.6).

### 6. Оценка
Отдельный агент/модель, свежий контекст, только `RUBRIC.md` + игра. Своя оценка не считается.
≥85 — PUBLISH; ниже — правится **только слабейший блок**, затем пересчёт.

### 7. Упаковка
```bash
node pipeline/pack.mjs ../games/<slug>          # собирает packages/<slug>/game.zip
node pipeline/pack.mjs ../games/<slug> --check  # валидация
node pipeline/audit.mjs ../games/<slug>         # 0 issues — зелёный свет
```
ZIP: `index.html` в корне, ASCII-имена, ≤100 МБ. Дальше — ручная отправка в Консоль.

## Частые причины отказа (закрыты автоматикой)

1. SDK встроен неправильно → `engine/sdk.js` копируется, не пишется заново.
2. `LoadingAPI.ready()` рано/не вызван → `main.js` вызывает после готовности сцены.
3. Не работает на мобиле/в портрете → скриншоты 720×1280 в capture, HUD-колонки.
4. Красные ошибки в консоли → console gate в каждом capture-скрипте и audit.
5. Нет офлайна → sdk-stub на `file://`, ноль сетевых запросов в audit.
6. Заглушки/пустые экраны → freeze-кадры play/shop/over в capture.

## Правила, добытые болью

- **Фиксированный шаг и ввод:** edge-флаги ввода гасятся только после реального update
  (`core.js`), иначе на 120–144 Гц теряется половина тапов.
- **Экономика — один кошелёк:** `storage['coins']`; не плодить `menuCoins`, иначе
  покупки/RV не доходят до забега.
- **no_ads** гасит баннер и interstitial, а не только одну кнопку.
- **HUD не наезжает:** левая колонка (уровень/ходы), панель целей, правая (монеты/очки),
  кнопка паузы — четыре независимые зоны; проверять на 360 и 720 ширины.
- **Портретный скриншот** надо смотреть глазами: автотест проверяет размеры, не вёрстку.
- **Промо-арт** рисуется `art.promo` через `pipeline/promo.html`; rng там — функция.
