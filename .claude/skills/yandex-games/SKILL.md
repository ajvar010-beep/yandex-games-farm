# Яндекс Игры: площадка и модерация

Площадка проверяет не «интересно ли», а соответствие регламенту: SDK, офлайн, медиа,
тексты, реклама. Отказ почти всегда по формальному пункту, а не по вкусу модератора.
Полная спецификация — `docs/yandex-specs.md` (157 пунктов) и `docs/yandex-submission-guide.md`.

## Рантайм

- **Никаких сетевых запросов из игры** (треб. 1.7). Всё локально: арт — код, звук — WebAudio,
  сохранения — `localStorage`.
- `LoadingAPI.ready()` вызывается один раз, **после** готовности первой сцены. Раньше — белый
  экран в проде, позже — долгая загрузка.
- SDK подключается только на `http/https`; на `file://` работает `sdk-stub.js`. Обе ветки
  обязаны давать одинаковое поведение.
- Игра живёт в iframe: `100dvh`, а не `100vh`; тач и мышь равноправны; пауза по
  `visibilitychange`; выход по Back/Escape — всегда доступен.

## Пакет (папка `packages/<slug>/`)

```
game.zip          index.html в корне, ASCII-имена, ≤100 МБ
media/            icon.png 512×512, cover.<lang>.png 800×470,
                  screenshot_landscape_*.png 1280×720, screenshot_portrait_*.png 720×1280,
                  gameplay_landscape.<lang>.mp4 (~26 с, H.264), qa_*.png
texts/            5 полей × 2 языка (ru/en)
CHECKLIST.md      что прогнано и чем
LICENSES.md       каждый ассет с лицензией (только CC0)
```

## Тексты карточки

Пять полей на язык: название, короткое описание, полное описание, instructions (управление),
seo-описание ≤160 символов. Название — до 50 символов. RU и EN пишутся независимо, не
калькой: EN-версия не должна быть длиннее и не должна оставлять английские слова в русской
карточке.

## Реклама

Баннер + interstitial между забегами + rewarded video по инициативе игрока (продолжить,
×2 монеты, разблок скина). `no_ads` гасит **и баннер, и interstitial**, а не одну кнопку.
RV не должен быть единственным путём к прогрессу — иначе модерация и отток.

## Частые причины отказа

1. SDK встроен кустарно (свой `ysdk`, а не `engine/sdk.js`).
2. `LoadingAPI.ready()` не вызван или вызван дважды.
3. Не работает в портрете / на мобиле; HUD наезжает на 360px ширины.
4. Красные ошибки в консоли — гейт по консоли обязателен.
5. Сеть в рантайме или игра не работает офлайн.
6. Заглушки и пустые экраны на скриншотах.
7. Текст обрезан на обложке 800×470.
8. Игра не выходит из паузы (или Back не работает).
9. Кнопка RV без награды / награда не выдаётся.

## Проверка перед отправкой

```bash
node pipeline/pack.mjs ../games/<slug> --check
node pipeline/release-check.mjs ../games/<slug>
```

`release-check` проверяет ровно те формальности, по которым чаще всего отказывают:
zip==исходники, свежесть медиа, RGB, RU≠EN на скриншотах, manifest↔код, мёртвые ключи,
выход из паузы.
