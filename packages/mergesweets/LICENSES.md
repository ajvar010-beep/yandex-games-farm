# Лицензии «Слияние Суфле» (mergesweets)

## Код и движок
- Собственный HTML5-Canvas движок фабрики (engine/*.js) — написан в проекте, свободен (MIT-стиль).
- Вся игровая логика (game/*.js) — собственная.

## Графика
- Вся графика (сладости, монета, промо-арт) — **процедурная**, рисуется кодом на canvas.
  Внешние изображения/модели/текстуры НЕ используются. CC0 (общественное достояние).

## Звук и музыка
- Все звуки и фоновая музыка — **процедурные**, синтезируются Web Audio API в момент
  воспроизведения (engine/audio.js). Внешние аудиофайлы отсутствуют. CC0.

## Шрифты
- Системные шрифты (system-ui, Segoe UI, Roboto) — поставляются ОС, внешние файлы не грузятся.

Внешних ассетов, требующих атрибуции, нет. CC-BY материалы не использовались.
