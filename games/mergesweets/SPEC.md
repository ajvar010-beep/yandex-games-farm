# SPEC — «Слияние Суфле» (mergesweets) v1.0

## Цикл
1. Сверху висит следующая сладость (тир 0–4), игрок двигает прицел перетаскиванием
   или A/D, отпускает/жмёт Пробел — сладость падает в стакан с физикой.
2. Две одинаковые сладости при касании сливаются в тир выше (до 10 «СУФЛЕ»).
3. Слияние даёт очки, монеты и прогресс целей уровня.
4. Когда все три цели выполнены — уровень пройден, стакан очищается, растёт сложность.

## Очки и награды
- Очки: 1/3/6/10/15/21/28/36/45/55/66 за тир (см. config.tiers).
- Монеты: за слияния + бонус за уровень (30 + 15×уровень).
- Прогресс: уровень, рекорд глубины; лидерборд `sweets_depth`.

## Проигрыш
- Шар, лежащий выше красной линии и почти остановившийся, дольше 0.4 с → стакан
  переполнен. Выход: rewarded «опустошить верх» (один раз за забег), заново, в меню.

## Между сессиями
- Монеты, уровень, рекорд, daily-стрик, no_ads, язык и mute — localStorage + облако
  (`player.setData` с конвертом `{save, savedAt}`).
- Ежедневная награда: база 100 + 50 за день стрика (макс. 500), опционально ×2 за RV.

## Магазин и монетизация
- Бустеры: бомба (нижний шар), встряска, радуга (следующий мерж с любым), плюс-тир;
  цена растёт ×1.28–1.40 за покупку.
- Rewarded: +120 монет в магазине, +120 в меню, ×2 к дейли, реанимация.
- Interstitial: не раньше 60 с игры, только живой игрок, не в no_ads.
- Баннер: только меню/пауза, скрыт при no_ads.
- IAP: coins_500, coins_1500, no_ads (цены показывает портал, не игра).

## Техника
- Движок: engine/* (fixed timestep 60 Гц, capture-хуки, SDK-адаптер).
- Ввод: Pointer Events + клавиатура; пауза по blur/visibility/рекламе.
- Офлайн: sdk-stub при file://, ноль сетевых запросов.
- Пакет: index.html в корне, ASCII-имена, ≤100 МБ.
