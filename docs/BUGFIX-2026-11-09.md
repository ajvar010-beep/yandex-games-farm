# Баг-фикс 2026-11-09: engine storage.remove + core.setScene

**Для следующего агента**: этот файл — журнал верификации. Каждая правка ниже
проверена гейтом; если что-то откатываешь — сначала прогони гейт заново.

## Что было сломано (подтверждено рантаймом)

### P0-1. `E.storage.remove is not a function`
- **Где**: blockfit, bubblepop, mahjongpair, merge2048, solitairekl, sudokulite
- **Триггер**: кнопка «Продолжить» / рестарт забега зовёт `E.storage.remove('<slug>_run')`
- **Корень**: в `engine/storage.js` был только `get/set/flush/authorize` — `remove` отсутствовал
- **Фикс**: добавлен `S.remove(key, immediate)` — удаляет ключ, пишет localStorage,
  планирует облачный flush. Симметричен `S.set`.
- **Проверка**: `node pipeline/release-check.mjs ../games/blockfit` — runtime-блок
  больше не содержит `pageerror: E.storage.remove is not a function`

### P0-2. `E.core.setScene is not a function`
- **Где**: те же 6 + fishpond (7 игр)
- **Триггер**: сцены вызывают `E.core.setScene(SC.play, {...})` как статик
- **Корень**: `E.core = { Game }` экспортировал только конструктор;
  `setScene` — метод экземпляра (`Game.prototype.setScene(name, params)`)
- **Фикс**: в `engine/core.js` добавлен легаси-шим `E.core.setScene(scene, params)`,
  который резолвит объект сцены в имя по `game.scenes` и делегирует текущему
  экземпляру. Текущий экземпляр регистрируется в `addScene` через `E.core._register(game)`.
- **Важно**: сигнатуры различаются. Живые игры зовут `game.setScene('play', params)`
  (имя строкой), сломанные — `E.core.setScene(SC.play, params)` (объект). Шим
  принимает оба вида.
- **Проверка**: `node pipeline/release-check.mjs ../games/fishpond` — runtime OK

## Раскатка

Движок `core.js` + `storage.js` до фикса был побайтово идентичен во всех 35 JS-играх
(md5: core `c0680b1d…`, storage `1a3eb34…`). После фикса раскатан на все 35 —
вариантов движка по-прежнему 1.

Эталон для копии: `games/parkingescape/engine/{core,storage}.js`.

## Что НЕ чинилось (и почему)

- **Мёртвые i18n-ключи** (18 игр): ключи есть в словаре, но не используются.
  Не крэш, просто мусор. Чистка — отдельной задачей.
- **Скриншоты RU==EN** (blockfit, mahjongpair, merge2048, solitairekl, starfall, wordlink):
  язык не переключился при capture. Требует пересъёмки медиа (`capture-<slug>.mjs`),
  не правки кода.
- **zip старше исходников** (rollfort, starfall + теперь все 7 пофикшенных):
  пересобирается `node pipeline/pack.mjs ../games/<slug>`. Сделано для 7 игр после фикса.
- **manifest.json отсутствует** (25 игр): release-check требует, но Яндекс берёт данные
  из формы Консоли. Решение о добавлении — за владельцем.

