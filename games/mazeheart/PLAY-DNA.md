# PLAY-DNA — «Сердце Лабиринта»

| поле | значение |
|---|---|
| Жанр | головоломка-побег в сеточном лабиринте |
| Глаголы цикла | читать · вести · собирать · избегать · открывать |
| Сессия | 30–90 с на лабиринт, 15–25 мин на кампанию |
| Камера | фиксированная, сверху, квадратное поле по центру |
| Управление | один жест: драг/свайп на клетку; стрелки на ПК |
| UI-зоны | HUD сверху (уровень, ключи, монеты, пауза), полоса жизней и цели снизу |
| Сложность | размер сетки 7→12, дозорных 1→3, скорость 1.7→2.8 |
| Прогрессия | 12 лабиринтов по порядку + 3 улучшения по 3 уровня |
| Мета | монеты за лабиринт, лавка смотрителя, рекорд |
| Монетизация | баннер в меню, interstitial между забегами, RV ×2 и второй шанс |
| Арт-направление | тёмный камень, мох, тёплые факелы, циановый огонёк, туман |
| Звук | процедурный: шаг, ключ, удар, победа; музыка 96 BPM |
| Ретеншн | «ещё один лабиринт» + видимый прогресс 1..12 + рекорд |
| Аудитория | 6+, казуальные игроки, которые любят думать и не любят экшн |

## Почему это работает одной фразой

Игрок видит весь лабиринт сразу и всё равно ошибается: решение принимается не в тумане,
а на глазах, и цена ошибки — одна жизнь и короткий возврат к последнему ключу.

## Что берём (формула)

- Сеточный лабиринт + ключи + выход — проверенная структура «путешествия к цели».
- Патрули по фиксированным маршрутам — давление без экшна: угроза читается и запоминается.
- Ключи как чекпоинты — мягкое наказание, игрок не переигрывает лабиринт целиком.
- Короткие уровни с растущим размером сетки.

## Что выбрасываем (облик и лишнее)

- Таймер и штраф за медлительность.
- Гачу, редкости, энергии, жизни-как-валюту.
- Отдельный экран выбора уровней и сложные туториалы.
