# PLAY-DNA — «Ядро» (архетип «артиллерия»)

Карточка снимается с **жанровой формулы**, а не с одной конкретной игры: баллистика —
архетип, который живёт с 1985 года (Artillery) и дошёл до мобильных в виде физических
головоломок. Ниже — что в нём работает и что мы взяли.

| Поле | Значение |
|---|---|
| **Ядро цикла (глаголы по порядку)** | наводись → оцени силу → выстрели → смотри полёт и рикошет → получи разбитые мишени → следующий рубеж |
| **Длина сессии** | уровень 15–60 с, забег 5–10 уровней (3–8 минут), «ещё один» — из-за короткого цикла |
| **Управление** | один палец: драг от пушки (угол = направление, сила = длина), отпускание = выстрел. Клавиатура — бонус |
| **Камера** | фиксированная, сбоку, весь полигон в кадре; никакого скролла — вся задача видна сразу |
| **Зоны UI** | ландшафт: слева панель (уровень, цели, ядра, монеты), справа арена, пауза в углу; портрет: верхняя полоса, арена, нижняя панель боезапаса |
| **Кривая сложности** | 1–2 мишени без стен → стены → щели и козырьки → качающиеся мишени; растёт не «HP», а число условий |
| **Прогрессия** | 15 рубежей подряд, открываются по одному, пройденные помечены |
| **Мета** | монеты за рубежи → 3 постоянных апгрейда (боезапас, пристрелка, замедление), цены растут |
| **Монетизация** | баннер в меню, interstitial между рубежами (каждый 2-й), RV: ×2 награда / второй шанс / монеты |
| **Арт-направление** | закатная пустыня: сиренево-медное небо, крупное солнце, слоистые дюны, сталь и латунь, песчаная пыль |
| **Роль звука** | подтверждает каждое действие: выстрел, отскок, взрыв мишени, победа; тихая пентатоническая музыка |
| **Хуки удержания** | «осталось одно ядро», мультикилл одним выстрелом, качающиеся мишени, магазин между рубежами |
| **Аудитория** | 12–45, casual, играет короткими сессиями в браузере и на телефоне |

## Почему это работает (одно предложение)

Баллистика даёт **мгновенную честную обратную связь**: видно ровно, где ошибся угол и сила,
и следующий выстрел можно сделать лучше — это чистый цикл «попробовал → понял → попробовал
снова» без чтения правил.

## Что оставляем

- Один жест наводки и мгновенный запуск — без туториалов и меню выбора оружия.
- Рикошет как второй слой решения (стена — не только препятствие, но и партнёр).
- Короткие уровни и быстрый рестарт: промах стоит 3 секунды, не 3 минуты.
- Мультикилл как источник «wow» и причина попробовать «идеальный кадр».

## Что выбрасываем

- Сюжет, персонажей, озвученные реплики, катсцены.
- Бесконечные генераторы уровней «то же, но больше стен» — вместо этого 15 авторских рубежей.
- Гачу, энергию, таймеры ожидания, лутбоксы.
- Тяжёлые текстуры и спрайты: всё рисуется кодом.
