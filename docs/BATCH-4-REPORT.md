## Волна правок по замечаниям рецензентов

**wordgrid** — IAP `no_ads`: восстановление по `productID` (SDK отдаёт именно
`productID`), цена из IProduct-каталога (`E.sdk.getCatalog`), рекорд после ×2;
магазин из паузы возвращает в паузу; зазор HUD между плашкой уровня и монетами.

**pindrop** — видимая кнопка паузы (была невидимой зоной клика), воронка не
срезается в ландшафте, описание товара по `E.ui.fit`; системная «Назад» на
победе/поражении; подписи бустеров 12+; контраст панели доски.

**pipes** — звёзды за ходы в плашке награды; «Второй шанс» не обещается без
кнопки; `openShop`/`closeShop` держат GameplayAPI; поворот при 0 ходов
запрещён; подпись рекламы 12 px; убрано мёртвое выражение.

**slide15** — плашка награды над кнопками; `openShop`/`_closeShop` держат
GameplayAPI; тосты на всех оверлеях; счётчик показывает остаток ходов;
награда не пишется в сейв при съёмке.

**dominochain** — двухрядная рука (10 костей не уезжают под лавку; 3 экрана);
раздача с `C.hand.max` и гарантией хода (18 000 стартов — 0 нарушений);
спасение из тупика: бесплатная перетасовка руки один раз за уровень, ревайв
сбрасывает шанс; кости при обмене не теряются (2400 прогонов — 0 потерь).

**mazeheart** — эффект урона в клетке столкновения; карта уровней в меню
(12 плиток, locked/done/★, «Назад», кадр в медиа); описание «Карты» = маршруты
дозорных; стартовая метка interstitial.

**pulseref** — после ревайва нет двойных монет/забега; темп музыки из
`st.info.bpm` (было `st.bpm` → 0 и вечные 96); interstitial при выходе на карту;
HUD 12.5.

**pixelcode** — IAP `no_ads` (каталог, восстановление, скрытие баннера и
рекламы); отметка «чисто» на пройденных уровнях.
**cannonball** — звёзды за экономию ядер на карте.
**lightout** — потолок цены бустеров 3× базовой.
