# PLAY-DNA — «Гвозди» (pindrop)

Формула взята не из одной игры, а из жанра **pull-the-pin / physics-ball puzzle**:
на доске висят шпильки, сверху падают шары, игрок выдёргивает шпильки и направляет
шары в контейнеры. Ниже — что в этой формуле работает и что мы берём, а что выбрасываем.

## Карточка ДНК

| Поле | Значение |
|---|---|
| Жанр | физика-лайт головоломка (pull-the-pin + pachinko) |
| Ядро цикла (глаголы) | смотри → тапни шпильку → шар падает и отскакивает → чаша заполняется → реши, что снять следующим |
| Длина одного уровня | 5–15 секунд на автопилоте, 15–40 у человека |
| Длина сессии | 5–10 уровней за заход (2–6 минут) |
| Управление | один тап по шпильке; никаких свайпов и перетаскиваний |
| Камера | фиксированная, 2D сбоку, вертикальная доска 2:3 |
| Зоны UI | верх/левая вывеска — уровень и шары; правая — монеты и бустеры; пауза в углу; низ портрета — три бустера |
| Кривая сложности | 15 уровней, каждый добавляет ровно один приём: второй бункер → решётка над чашей → две чаши по два шара → два бункера сразу |
| Прогрессия | линейная лестница 15 уровней, номер текущего уровня = прогресс |
| Мета | мастерская: запас шаров, тормоз, клещи — покупаются монетами, цены растут |
| Монетизация | баннер в меню, interstitial после каждого 2-го уровня, RV ×2 награда и +3 шара |
| Арт | мастерская: тёмное дерево, воронёная сталь, янтарь, искры. Всё рисуется кодом |
| Звук | процедурный WebAudio: щелчок шпильки, звон шара о чашу, тихий пентатонический фон |
| Крючки возврата | «ещё один уровень» (короткий), рекорд «дошёл до N», покупка в мастерской |
| Аудитория | 6+, казуальная головоломка, играет и в портрете, и в ландшафте |

## Почему формула работает

Физическое действие **читается мгновенно**: тапнул — шпилька исчезла, следующий шар поехал
иначе. Ошибка не наказывает сразу: шары идут потоком, поэтому у игрока есть несколько
попыток настроить маршрут и почувствовать себя мастером.

## Что забираем

- Глагол «выдерни шпильку» и мгновенную физическую обратную связь.
- Контейнеры с квотой вместо очков: цель видна глазами, а не цифрой.
- Короткий уровень, который перезапускается одним тапом.
- Поток шаров вместо одного шара: одна шпилька меняет судьбу не одного броска, а серии.

## Что выбрасываем

- Чужие имена, логотип, персонажей, спрайты, уровни, музыку и тексты.
- «Спаси персонажа» — у нас нет персонажа и драмы спасения, только мастерская и чаши.
- Случайность в логике: вся физика детерминирована, уровень проходится одним и тем же
  порядком действий (это и есть сохранённый план автопилота).
