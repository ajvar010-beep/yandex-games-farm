# «Про Паркур» (Pro Parkour) — дизайн-документ

Серия майнкрафт-паркуров для Яндекс.Игр. Одна кодовая база, скины/сложность через конфиг → Нубик / Про / Бог.

## Формула (по анализу топов)

Майнкрафт-паркур = 3D-платформер с кубическим воксельным визуалом:
- Вид от 3-го лица (за спиной), персонаж — блочный гуманоид
- Прыжки по платформам над лавой/пропастью
- Чекпоинты (флаги), монеты (звёзды/изумруды), финиш
- Ловушки: движущиеся платформы, исчезающие блоки, маятники, поршни
- Скины (нуб → про → бог — прогрессия статуса)
- RV: revive после падения, разблок скина, подсказка

## Почему зарабатывает

- Ребёнок видит знакомый майнкрафт-стиль → кликает
- Простая механика (бег+прыжок) → низкий порог входа
- Падение в лаву = фрустрация → RV-revive (основной доход)
- Скины = статус → RV на разблок + гринд
- Много уровней → время сессии → interstitial

## Технический стек

- **Godot 4.7.2** (portable, MIT) → Web export (HTML5/WebGL)
- Весь код текстом: .gd (GDScript), .tscn (сцены), project.godot
- Генерация уровней из JSON (levels/*.json) — легко делать 100+ уровней
- Процедурные текстуры/модели (блоки = BoxMesh + StandardMaterial3D) — нет внешних ассетов по умолчанию
- Yandex SDK через JavaScriptBridge (обёртка в scripts/yandex.gd)

## Архитектура сцен

```
Main.tscn          — точка входа, загрузка, переходы
Menu.tscn          — главное меню (уровни, скины, настройки)
Game.tscn          — геймплей: Level + Player + Camera + HUD + UI слои
  ├─ Level (Node3D) — генерирует платформы из JSON
  ├─ Player (CharacterBody3D) — бег/прыжок/двойной прыжок
  ├─ CameraRig (Node3D) — follow-камера за спиной
  ├─ HUD (CanvasLayer) — монеты, время, кнопки
  └─ UI (CanvasLayer) — пауза, смерть, победа, revive
Shop.tscn          — магазин скинов (RV/монеты)
```

## Механики игрока (CharacterBody3D)

- WASD/стрелки/свайп — движение (8 направлений)
- Space/тап — прыжок, двойной прыжок (в воздухе 1 раз)
- Shift — спринт
- Койот-тайм (0.12с) + буфер прыжка (0.15с) — forgiving platforming
- Падение в лаву/за край → смерть → revive (RV) или рестарт с чекпоинта

## Монетизация (цель — деньги)

| Точка | Тип | Что даёт |
|---|---|---|
| Revive после смерти | RV | продолжить с места смерти |
| Разблок скина | RV | новый скин бесплатно (или монеты) |
| Подсказка (показать путь) | RV | временная подсветка маршрута |
| Между уровнями | interstitial | каждые ~90-120с, не чаще |
| IAP (позже) | payments | набор монет, «без рекламы» |

## Уровни

JSON: массив платформ {x,y,z, sx,sy,sz, type, color}, старт, финиш, чекпоинты, монеты, ловушки (move: {axis, range, speed}).

Генератор уровней: 3 акта сложности (нуб/про/бог), длина прыжка растёт, платформы уже, ловушки плотнее.

## Серия (одна кодовая база)

| Игра | Сложность | Скин | Тон |
|---|---|---|---|
| Нубик Паркур | easy | нуб (зелёный) | дружелюбно |
| Про Паркур | normal | про (синий) | спортивно |
| Бог Паркур | hard | бог (золотой) | эпично |
