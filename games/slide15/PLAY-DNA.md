# PLAY-DNA — «Латунный Порядок» (slide15)

Карточка формулы, а не облика. Источник — классическая пятнашка (15-puzzle), механика
общественная, как шахматы: играем в неё, а не копируем чей-то продукт.

## Что это за игра

Сдвижная головоломка: на доске n×n стоят пронумерованные плитки, одна клетка пустая.
Тап по плитке рядом с пустой передвигает её. Цель — расставить номера по порядку,
пустая клетка в правом нижнем углу.

## Поля карточки

| поле | значение |
|---|---|
| **Жанр** | puzzle / sliding-tile, спокойный, без таймера |
| **Глаголы ядра** | тапнуть → сдвинуть → увидеть, как доска приближается к порядку |
| **Длина сессии** | 1–3 минуты на доску; забег — 3–6 досок подряд |
| **Управление** | один палец, один тап; никаких свайпов и жестов |
| **Камера** | фиксированная, доска целиком, без скролла |
| **Зоны UI** | уровень слева сверху, ходы/пар/монеты — строка статуса, пауза справа, действия снизу (портрет) или сбоку (ландшафт) |
| **Кривая сложности** | 3×3 → 4×4 → 5×5; растёт и пар, и лимит ходов |
| **Прогресс** | 12 досок, открываются по одной, рекорд по ходам на доску |
| **Мета** | монеты за доску, магазин из трёх расходников |
| **Монетизация** | баннер в меню, interstitial между забегами, RV «×2» и «продолжить» |
| **Арт-направление** | мастерская: тёмный орех, латунная рама, кремовые плитки с гравировкой |
| **Звук** | короткий деревянный щелчок на сдвиг, латунный звон на победу |
| **Хуки удержания** | «ещё один ход», рекорд по ходам, открытие следующей доски |
| **Аудитория** | 25–65, любители спокойных логических игр, играют в метро и перед сном |

## Почему это работает (одна фраза)

Правила понятны за две секунды, а каждый тап немедленно и честно меняет доску —
мозг сам видит, стало ли ближе к порядку, и требует ещё один ход.

## Что берём

1. **Правило одного хода**: тап по соседней плитке, ничего больше.
2. **Пар как цель**: «собрать за N ходов» превращает песочницу в задачу.
3. **Рост сетки**: 3×3 учит, 4×4 нагружает, 5×5 держит надолго.
4. **Обратная последовательность перемешивания** как честное решение уровня.

## Что выбрасываем

- Чужие картинки на плитках, логотипы и названия «15 puzzle».
- Таймер на каждую доску (спешка убивает жанр).
- Рекламу на каждом ходу и принудительный RV.
- Гачу, лутбоксы, «энергию» и прочие стены.

## Чем наша версия отличается

Доска — **латунная панель из мастерской**: плитки с гравировкой, рама с винтами,
тёплый орех. Плюс **пар-ходы и лимит** вместо бесконечного перебора: уровень — это
задача, а не песочница. И магазин расходников (подсказка/отмена/перемешать) вместо
скинов.
