# PLAY-DNA — «Слово-Сетка»

ДНК жанра «поиск слов»: что именно делает цикл рабочим и что из этого мы воспроизводим.
Источник — разведка партии-4 (`market/play-batch-2026-11-07.md`), скан топа Яндекса
`market/scan-2026-11.md` (2026-11-06), формула жанра word search, без переноса облика.

## Карточка

| поле | значение |
|---|---|
| Жанр | поиск слов (word search), казуальная головоломка |
| Ядро (глаголы) | разглядеть → провести по буквам → слово найдено → вычеркнуть → искать следующее |
| Длина сессии | 1.5–2.5 мин на уровень, 3–6 минут на заход |
| Управление | свайп по линии через соседние клетки; тап по кнопкам HUD |
| Камера | фиксированная, вид сверху, вся сетка на экране целиком |
| Зоны UI | верх: уровень/тема, монеты, лавка, пауза, полоса таймера; центр: сетка; низ (портрет) / справа (ландшафт): список слов |
| Кривая сложности | 8×8 / 5 слов → 10×10 / 6–7 → 12×12 / 7–8; тема меняет словарь, таймер растёт медленнее объёма поиска |
| Прогрессия | 12 уровней по темам, открываются по порядку, рекорд счёта, монеты |
| Мета | лавка из трёх бустеров, цена каждого растёт с покупками |
| Монетизация | баннер в меню, interstitial между уровнями (каждый второй), RV «×2», «продолжить», «монеты» |
| Арт | бумага и чернила: рукописная сетка, маркерные штрихи, круглый штамп, жетоны-ярлычки |
| Звук | процедурный WebAudio: тики на каждой букве, монета на слове, фанфара на уровне |
| Ретеншн | смена 12 тем, рекорд, «продолжить с уровня N», понятная цель «найди все» |
| Аудитория | 25–65, играющие в слова/кроссворды на телефоне; RU и EN |

## Почему это работает — одной фразой

Мозг получает быстрый и честный дофамин: слово было спрятано в шуме — и вдруг сложилось
под пальцем; список целей и таймер не дают заскучать, а тема даёт каждому уровню лицо.

## Что оставляем

- Свайп по линии и мгновенную подсветку найденного (главный «вкус» жанра).
- Список слов рядом с сеткой — цель всегда видна.
- Таймер и три бустера: подсказка, перемешать, +время.
- Награду за каждое слово, а не только за уровень.

## Что выбрасываем

- Облик, имена, логотипы и ассеты любых конкретных игр — рисуем своё.
- Бесконечные жизни/энергию и гачу — лишний барьер для казуалки.
- Лишние экраны (карта, аватары, скины) — 12 уровней и лавка покрывают мету.

## Наш сдвиг

Тема уровня — не только фон, а **словарь и цвет**: 12 тем (море, лес, космос, кухня,
спорт, музыка, огород, город, зима, школа, праздник, путешествие), у каждой свой набор
из 12–16 слов на RU и EN. Сетка растёт вместе с темой, поэтому «ещё один уровень» — это
новый мир слов, а не та же сетка с другими буквами.
