# Слейт партии «топ-жанры» (цель — вершина Яндекс Игр)

Отбор по исследованию TOPS-2026-10. Каждый концепт — уникальный жанр/механика (треб. 3.6: не дублировать),
свой вариант промо (5.1.1.1), своя палитра. Каркас — наш движок (core/capture/sdk/i18n/audio/ui/fx/storage/rng),
RU+EN, облачные сейвы, rewarded, стики-баннер вне геймплея, 20 уровней или бесконечный режим с мотивацией (2.9).

## Процесс (на каждую игру)
1. Билд на движке (games/<id>/) — config/entities/art/i18n/scenes/main + index.html + sdk-stub.
2. capture-<id>.mjs → media (скрины RU/EN, видео, icon/cover).
3. montage.mjs → gameplay_landscape.{ru,en}.mp4.
4. pack.mjs + --check; audit.mjs — 0 issues.
5. **Консилиум ×10** (Workflow): балл = механика 30 / вайб 25 / монетизация 20 / реализация 25.
   ≥8.0 → в счёт (публикация). <8.0 → остаётся в репо, в счёт не берём, фиксируем в research/verdicts/.
6. commit + push в приватный репозиторий.
