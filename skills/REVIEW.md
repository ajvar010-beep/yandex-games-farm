# Проверка внешних скиллов (2026-10-18)

Прочитаны и допущены (только учебный контент, без команд/сети/подозрительных инструкций):

- `puzzle-match3.md` — плейбук досковых головоломок (match-3 resolve/cascade/refill, undo,
  solvability). Источник: gamedev-skills/awesome-gamedev-agent-skills.
- `card-game.md` — плейбук карточных игр (зоны, draw/reshuffle, ресурсы, разрешение эффектов).
  Тот же источник.
- `game-engine-html5.md` — обзорный скилл по веб-движкам (game loop, Canvas/WebGL, ввод, аудио,
  публикация). Источник: github/awesome-copilot.

Метод: скачивание → чтение содержимого → поиск паттернов (curl/exec/eval/токены/jailbreak) →
перенос в `skills/`. Ничего не выполняется автоматически; это справочники.
