## Часть 3. Кросс-платформенный слой (главная работа сессии)

**Задача**: спроектировать и реализовать слой для кросс-публикации 35 JS-игр на
Яндекс + VK + GameMonetize. Выбор пользователя: первая платформа — **VK**, раскатка —
**сначала на эталоне parkingescape, потом скриптом на остальные**.

### Ключевое архитектурное решение
Контракт `E.sdk.*` уже был кросс-платформенно чистый (реклама/gameplay/лидерборды/платежи
работают через `K.ysdk`). Поэтому игровые сцены **не трогал вообще** — меняется только
адаптерный слой: кто создаёт объект `ysdk`.

### Добавлено (новые файлы, в каждой из 35 игр)
- **`engine/platform.js`** — грузится ПЕРВЫМ. Детект платформы по `location.hostname`,
  инжект её SDK через `document.write` до движка:
  yandex→`/sdk.js`; vk/vkplay/userapi→vk-bridge (jsdelivr CDN);
  gamemonetize→`api.gamemonetize.com/sdk.js`; иначе→standalone (общий sdk-stub.js).
- **`engine/platform/vk.js`** — адаптер VK Bridge под контракт ysdk. Реклама:
  `VKWebAppShowNativeAds` (interstitial/reward), `VKWebAppShowBannerAd` (стики); облако:
  `VKWebAppStorageGet/Set`; платежи: `VKWebAppOpenPayForm`; лидерборды:
  `VKWebAppShowLeaderBoardBox`. Язык из launch-параметров.
- **`engine/platform/gamemonetize.js`** — адаптер GameMonetize: `SDK_OPTIONS{gameId,
  onEvent}` + `sdk.showBanner()`. Сохранения в localStorage (облака у GM нет). Платежей нет.

### Изменено
- **`engine/sdk.js`** — `K.init()` стал диспетчером: роутит по `Engine.platform`.
  Вся нижележащая логика (реклама, gameplay, лидерборды, платежи) не изменилась.
- **`index.html` ×34** — IIFE `document.write('/sdk.js')` заменён на
  `platform.js` + `sdk-stub.js` + адаптеры vk/gamemonetize. Скрипт:
  **`pipeline/_xplat_rollout.mjs`** (новый, идемпотентный).

### Удалено (находка)
- **`games/parkingescape/engine/engine/`** — мёртвый дубликат старого движка от 06.11
  (10 файлов, 84КБ). Не грузился (index.html его не трогал), но попадал в каждый zip —
  лишний вес и рассинхрон. Единственная игра с таким дубликатом.

### Гейты
- Синтаксис всех новых/изменённых файлов: OK.
- smoke ×35 → 0 issues.
- Детект платформы юнит-проверен на 11 кейсах (yandex/vk/gamemonetize/standalone) — точный.
- zip ×35 пересобраны, все содержат platform.js. starfall.zip теперь свежий (md5 совпал).
- release-check parkingescape: только «медиа старше кода» (ожидаемо — код правил), без

### Продакшн-баг: 5 игр показывали ТОЛЬКО английский
- **Корень**: blockfit, mahjongpair, merge2048, solitairekl, sudokulite имели
  `G.i18n` как объект-метод `{lang,t,setLang,list}` БЕЗ полей `ru`/`en`. Игра рендерит
  через `E.i18n.t()`, но `E.i18n.init(G.i18n, lang)` ждёт словарь → получал пусто →

- **Это не capture-баг — реальные русские игроки видели английский.**
- **Фикс**: в G.i18n добавлены `ru: STR.ru, en: STR.en`. E.i18n получил словарь,
  кнопка смены языка заработала. Проверено: RU/EN разные заголовки, smoke 5/5.
