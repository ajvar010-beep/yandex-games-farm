# PLAY-DNA — карточка разбора игры

Заполняется до дизайна. Один экран, без воды. Если поле не проверить — пиши «не проверено»
и источник, а не придумывай.

```markdown
# PLAY-DNA: <название> (<package>)
Дата снимка: YYYY-MM-DD · Источники: <URL1>, <URL2>

## Рынок
- Рейтинг: X,X (N отзывов) · Установки: <диапазон> · Цена/IAP: <...>
- Позиция в чарте: <страна/категория/место или «не видно»>
- Похожие: <3–6 игр> · Отзывы хвалят: <...> · Ругaют: <...>

## Формула
- Жанр: <...> · Камера: <2D сверху / сбоку / 3D / изометрия>
- Ядро (глаголы по порядку): <тапнул → ... → ... → награда>
- Сессия: <30 с / 2 мин / 10 мин> · Уровень: <длина, кривая сложности>
- Управление: <1 палец / свайп / drag> · Обратная связь: <звук, частицы, тряска>
- Прогресс: <уровни/тиры/скины> · Мета: <магазин/бустеры/дейли/лидерборд>
- Монетизация: <баннер/интерстишл/RV/IAP> · Реклама в цикле: <где именно>
- Арт: <палитра-семейство, формы, настроение> · Звук: <роль, стиль>
- Удержание: <что возвращает на следующий день>

## Почему работает (одно предложение)
<...>

## Берём / выбрасываем
- Берём: <механика, темп, структура экономики>
- Выбрасываем: <чужие образы, имена, точные раскладки, объём контента>
- Наш поворот: <новый глагол/тема, который меняет ощущение>
```

## Пример заполнения (условный болт-пазл)

- Жанр: сортировка-пазл · Камера: 2D сверху, фиксированная.
- Ядро: выбрать болт → выкрутить в ящик цвета → плита без опоры падает → открывается
  следующий слой → «чисто».
- Сессия 2–3 мин, уровень 40–90 с, сложность скачками каждые 5 уровней.
- Монетизация: интерстишл между уровнями, RV «лишний ящик», баннер в меню.
- Арт: тёмный фон, яркие насыщенные болты, крупные скругления; звук — щелчки и падения.
- Почему работает: каждый ход меняет доску целиком, падение — бесплатная награда-сюрприз.
- Наш поворот: механизмы, которые после разборки оживают анимацией, и генератор «снарядом
  назад» — нерешаемых досок нет.
