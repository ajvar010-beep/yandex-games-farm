# Яндекс Игры — авторитетные требования (SNAPSHOT 2026-10-12)

Источник-первоисточник: `docs/yandex-doc-snapshot.json` (официальная дока
`yandex.ru/dev/games/doc/ru/concepts/requirements`, ред. от 9 сен 2026, 157 пунктов).
Размеры ассетов кросс-проверены по `docs/yandex_spec.json` (цитирует
`yandex.com/dev/games/doc/en/concepts/requirements` + поля формы черновика).

> **Правило расхождений:** точные пиксели/лимиты формы черновика побеждают этот файл.
> При первой реальной загрузке сверить с формой и поправить тут же.

## 1. АССЕТЫ — точные размеры

| Ассет | Размер | Формат | Лимит | Кол-во | Примечание |
|---|---|---|---|---|---|
| **Иконка** | ровно 512×512 | PNG/JPG | ≤1 МБ | 1 | Квадрат, без рамок/скруглений. **НЕ скриншот из игры** (5.6). |
| **Обложка (cover)** | ровно 800×470 | PNG/JPG | ≤2 МБ | 1 | Промо-баннер. **НЕ скриншот из игры** (5.6). |
| **Скриншот (альбомный)** | 16:9, длинная сторона 1280–2560 (напр. 1280×720 или 1920×1080) | JPEG или 24-бит PNG без альфы | ≤5 МБ | **≥3** на язык | **РЕАЛЬНЫЙ геймплей ≥70% кадра** (5.1.1.2). Консоль ОТКЛОНЯЕТ одинаковые скрины. |
| **Скриншот (портретный)** | 9:16, длинная сторона 1280–2560 (720×1280) | JPEG/24-бит PNG без альфы | ≤5 МБ | 0–20 | Только если заявлены мобильные скрины. |
| **Видео (горизонтальное)** | 16:9, H.264 MP4 (1280×720) | mp4 | ≤100 МБ, **≤28 сек** | **1 ОБЯЗАТЕЛЬНО** (красная звёздочка в форме) | **РЕАЛЬНЫЙ геймплей ≥70% длительности** (5.1.1.3). Без моков/оверлеев. |
| **Видео (вертикальное)** | 9:16, H.264 MP4 (720×1280) | mp4 | ≤100 МБ, ≤28 сек | 0–6 | Опц., но мобильной игре без него нечего показать телефонным игрокам. |

Скрины делятся ДВАЖДЫ: по платформе (Десктопные/Мобильные) и по ориентации; пара — на каждый язык.
Видео хранится как один слот на ориентацию, несущий по файлу на язык.

**Формат видео для ffmpeg** (рендер из покадровых PNG):
```bash
ffmpeg -y -framerate 30 -i frames/f_%04d.png -c:v libx264 -pix_fmt yuv420p -crf 20 -t 28 out.mp4
```

## 2. ТЕКСТЫ — 5 полей на язык (RU + EN оба обязательны)

| Поле | Файл | Лимит | Правило |
|---|---|---|---|
| **Название** | `title.<lang>.txt` | ≤50 симв. | Идентично в игре и во ВСЕХ материалах (5.1.3). Уникально в каталоге на каждый язык (5.12). **БЕЗ слов «игра»/«game»** (6.5). Лаконичное (6.6). |
| **SEO-описание** | `seo.<lang>.txt` | ≤160 симв. | Одно предложение для поиска. |
| **Короткое описание** | `short.<lang>.txt` | ≤70 симв. | Строка под названием в тайле каталога. |
| **Об игре** | `about.<lang>.txt` | 100–1000 симв. | Отражает реальную механику (8.2.2). |
| **Как играть** | `how_to_play.<lang>.txt` | 40–1000 симв. | Управление ПОЛНОСТЬЮ описано здесь или в игре (2.2). |

**Общее (заполняется один раз):**
- Ключевые слова (через запятую): **≤100 симв.**
- Комментарий разработчика: **≤2048 симв.**
- Версия: `0.0.0.1`
- Платформы: Десктопные, Мобильные, Планшеты
- Возрастной рейтинг: 0+/6+/12+/16+/18+
- Категории: 1–2; Теги: 3–5
- Облачные сохранения: Да (если `player.setData()/getData()`)

**Правила текстов (8.2, 5.11):**
- EN = НАСТОЯЩИЙ перевод RU, не копия (совпадать может только название-имя собственное).
- Без мата на любом языке (8.2.4), без запрещённых материалов.
- Орфография/пунктуация языка (8.2.1).
- Запрещены повторяющиеся символы для накрутки длины и дубли текстов между полями (5.11).
- Тексты, влияющие на геймплей, переведены на язык (8.2.3).

## 3. SDK / РЕКЛАМА — обязательная интеграция

- **1.1** SDK Яндекс Игр встроен: `<script src="/sdk.js"></script>` → `YaGames.init()`.
- **1.19.2** `LoadingAPI.ready()` — когда игрок может начать.
- **1.19.3** `GameplayAPI.start()` / `GameplayAPI.stop()` — разметка геймплея.
- **1.19.4** `ysdk.on('EXIT'/...)`, события `game api pause` / `game api resume`.
- **4.1** Реклама ТОЛЬКО через SDK. Никаких сторонних рекламодателей, статичных рекламных картинок/текста.
- **4.7** При показе fullscreen (interstitial/rewarded) — **звук и геймплей на ПАУЗЕ**.
- **4.5** Rewarded video — по желанию пользователя (кнопка), награда = бонус (бустеры/доп.ходы/пропуск уровня), **не блокирует продолжение игры**.
- **4.6** Доп. рекламные блоки = ТОЛЬКО стики-баннеры (`showBannerAdv`). Кастомные RTB-баннеры запрещены.
- **1.16** Нельзя модифицировать/имитировать рекламные блоки (свои фейковые fullscreen/RV).
- **2.14** Автоопределение языка через SDK (`ysdk.environment.i18n.lang`).
- **1.3** При потере фокуса — звук останавливается.
- **1.9 / 1.11** Прогресс сохраняется сразу; облачные сейвы (`player.setData/getData`) → включить опцию в черновике.

**Методы SDK (подтверждены):**
```js
ysdk.adv.showFullscreenAdv({ callbacks: { onOpen, onClose(wasShown), onError } })   // onClose+onError обязательны
ysdk.adv.showRewardedVideo({ callbacks: { onOpen, onRewarded, onClose, onError } }) // onRewarded для награды
ysdk.adv.showBannerAdv() / hideBannerAdv() / getBannerAdvStatus()                   // Promise {reason, stickyAdvIsShowing}
```
Лимит: fullscreen слишком часто → «too frequent requests» пропускается. Держать кулдаун (~60с).

## 4. БИЛД — жёсткие правила

- **1.21** Все файлы ≤ **100 МБ** в разархивированном виде.
- **1.22** `index.html` **В КОРНЕ** архива. Имена файлов/папок — **без пробелов и кириллицы** (ASCII).
- **1.23** ⛔ **Интерактивный ИИ в играх ЗАПРЕЩЁН.** (Заранее сгенерированные ИИ-материалы — можно.) → В рантайме игр НЕ должно быть live-LLM/нейровызовов. Наш Canvas-код самодостаточен — ок.
- **1.7** Никаких абсолютных URL на S3 Яндекса.
- **3.9** Видео без перехода на внешние ресурсы; **YouTube-интеграция ЗАПРЕЩЕНА** → свой хостинг или видео в архиве.
- **8.4.2** Никаких ссылок на внешние ресурсы (сайт студии, сторы, скачивание). Бренд без URL — можно.
- **1.18** Работа игры не ограничена URL, на котором открыта.
- **6.4** При открытии DevTools — **НЕТ ошибок в консоли**.

## 5. КАЧЕСТВО ГЕЙМПЛЕЯ (порог модерации 2.x)

- **2.8** Нарастающая сложность + понятный сюжет/сеттинг.
- **2.9** Прохождение основы **>10 минут** ИЛИ мотивация перепроходить.
- **2.4** Минимум один критерий игровых механик.
- **2.3** Соответствие заявленному жанру.
- **2.13** Рейтинг должен быть **>30**, иначе снимут с публикации через 3 недели.
- **6.2** Возможность отключить звук. **6.3** Возможность паузы.
- **1.14** Без ошибок/зависаний/вылетов при повороте экрана, лонгтапе, жестах, сворачивании, показе рекламы, переходах по истории.
- **1.6.2.4** Десктоп: управление клавиатурой/мышью, **не зависит от раскладки** (использовать `event.code`, не `key`).
- **1.6.1.5 / 1.10.4** Мобильные: полное управление жестами, одной рукой, основной экран без прокрутки.
- **1.10** Корректное отображение при resize/повороте: элементы не обрезаются, нет браузерного скролла/swipe-to-refresh, тексты не накладываются.
- **6.8** Обучение (tutorial) для сложной механики — рекомендуется.

## 6. ЗАПРЕЩЁННОЕ СОДЕРЖАНИЕ (3.x, 8.x)

- **3.4.4** Политика, политические деятели, конфликты, войны.
- **3.4.5** Религия, религиозные деятели/атрибуты.
- **3.4.2** Чёрная магия; инап-покупки в играх с гаданиями.
- **3.4.3** Реалистичное насилие над животными/детьми/пожилыми.
- **3.7** Нельзя выиграть реальные деньги/призы/товары/промокоды.
- **8.2.4** Мат на любом языке.
- **3.6** Не копировать другую игру из каталога и не дублировать свои; сиквел — только при полной переработке сеттинга/механик.
- **8.3.3** Медиа без рамок и скруглённых углов.
- **8.3.1** Хорошее техкачество, без артефактов сжатия, одноцветных кадров, обрезанного текста в иконке/обложке.
- **5.1.1.1** Не использовать геймплей ДРУГИХ игр; промоматериалы НЕ идентичны между играми.

## 7. ЧТО НУЖНО ДЛЯ ОТПРАВКИ (SUBMIT)

- **6.1** Email для обратной связи.
- **RSYA-контракт (договор с Рекламной сетью Яндекса)** — **ОБЯЗАТЕЛЕН для SUBMIT**. Форма пишет об этом над кнопкой отправки. НЕ блокирует заполнение/сохранение черновика. → **Действие пользователя в консоли до отправки на модерацию.**
- Обязательные поля заявки (5.2): Название, Об игре, Как играть, Версия, Категории, Иконка, Обложка, Архив, Поддерживаемые платформы, Ориентация + скриншоты.

## 8. ПАРАМЕТРЫ ПАРТИИ (решения пользователя, 2026-10-14)

- Публикация: аккаунт есть, загрузка **вручную** → готовим полные пакеты `packages/<game>/` для копипаста в консоль.
- Жанры: **решает ИИ** → сбалансированный портфель, без повторов (3.6!), каждый с уникальной механикой/палитрой.
- Масштаб: **полная /arena (100 агентов)** за эталонный движок → **10+ игр**.
- Гео: **RU + EN**, БЕЗ worldwide-флага → реклама остаётся активной.
- Строитель игр: **Kimi K3** (роутер: opus-слот `ANTHROPIC_DEFAULT_OPUS_MODEL=kimi-k3`).

## 9. КЛЮЧЕВОЙ ВЫВОД ДЛЯ МЕДИА-ПАЙПЛАЙНА

Иконка/обложка = **стилизованный промо-арт** (НЕ скриншоты).
Скриншоты/видео = **ЗАХВАТ РЕАЛЬНОГО ГЕЙМПЛЕЯ** (≥70%). Значит движок обязан иметь
**детерминированные capture-хуки**: скрипт прогоняет игру в заданные состояния → headless
Chrome делает кадры → ffmpeg собирает mp4 ≤28с. Нарисованные «фейк»-промо для скринов/видео = ОТКЛОНЕНИЕ.
