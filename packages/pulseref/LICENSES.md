# Лицензии — «Пульс»

Внешних ассетов нет: все изображения, иконки, обложки, эффекты и звуки
создаются кодом во время выполнения.

| Компонент | Происхождение | Лицензия |
|---|---|---|
| `engine/*.js` | движок фабрики (копия 1:1 из `games/parkingescape/engine`) | внутренний, репозиторий фабрики |
| `sdk-stub.js` | заглушка Яндекс SDK фабрики (только для офлайна/разработки) | внутренний, репозиторий фабрики |
| Арт (небо, солнце, сетка, ноты, иконка 512, обложка 800×470) | `game/art.js`, процедурная графика Canvas | оригинальная работа фабрики |
| Звук (клики, бит, итоги) | `engine/audio.js`, процедурный WebAudio | оригинальная работа фабрики |
| Шрифт | системный `system-ui` (не встраивается и не поставляется) | системный |

CC0-ассеты (Kenney и др.) в этой игре не использовались.
